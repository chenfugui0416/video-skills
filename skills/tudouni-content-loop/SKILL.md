# 土豆泥口播闭环

把有依据的材料交给指定写作者，审核后将纯定稿交给已有视频链。默认由当前 agent 控制 ego，不启动其他 agent。沿用当前任务与账号决策，不把示例的受众、题目或模型固定成全局规则。

## 范围与准备

- 先识别本次到写稿、定稿、试片、完整视频还是平台适配。要求制作视频已包含必要的配音、对齐与渲染；已授权步骤继续执行，不重复问音色或视觉。正式发布单独遵守项目规则。
- 读取对应项目规则、当前事实源与相关制作状态。已有发布包复用；新发布任务按原工作区结构创建。私有同题对照可在原项目的独立版本目录执行，不覆盖既有定稿、音轨和成片。
- `原文.md` 或用户明确提供的源稿是事实源。写作包只存当次快照与哈希，不成为另一份事实库。模型名称或文章目标确实不明确时简短问清，继续不依赖答案的工作。
- 依赖：已安装的 `ego-browser`、`tudouni-ai-video`，以及其 HyperFrames 与豆包配音链。先核实已有路径，不自动重装。首次使用浏览器按 ego 技能读当前 API。

## 执行

0. **选题研究**：先按 [热点与爆款研究](references/topic-research.md) 收集同领域近期热门话题和可核验的爆款案例，记录时间、链接、可见指标与采样局限，给出与账号相关的候选及推荐。借鉴问题、结构和证据，不洗稿，不把播放量当作事实正确的证明。用户已指定题目时只补相关研究，不擅自换题。

1. **整理写作包**：按 [交接字段](references/editorial-contract.md) 写 `packet-v01.json`。内容包含一个观众任务、相关原稿/提纲、编号事实和边界、锁定原话、可展示证据、长度目标与唯一行动引导。资料不全先补事实，不能让写作者造经历。使用 `editorial.py export` 导出最小外发提示词。
2. **ego 写作**：本工作流默认由 ego 内 Gemini 第4代写作，当前已核验可用的写作选项是 `4 Hydrogen`；每次按菜单重查实际标签，不把示例当永久型号。按 [ego 写作操作](references/ego-writer.md) 执行；要求 Jev 时按 [Jev 接入](references/jev-control.md) 让其判断下一步，agent 核对后用 ego 执行。Jev 是页面判断模型，与实际写作模型分别记录。核对页面实际模型，完整发送一次，读回当前回答并保存原始文本和无账号值的 receipt。同任务修订复用原对话。Gemini 不可用、型号不符或需要登录时保留现场并报告，不静默换 API 或当前模型。用户另行指定本地写作时才用 `local`，不冒称 Gemini 参与。
3. **接收与审核**：运行 `editorial.py accept`，只提取完整 JSON 中的纯口播。对照事实源核对事实、原意、口播可读性、画面证据四项，将审核绑定本版正文哈希。由 Codex 逐句审核；发现具体缺陷就在原对话给出问题句、依据和改写目标，递增版本并要求完整重写或定点润色，其他合格表达保留。复审仍不合格继续返工，不因通过格式检查就冻结。连续三轮无改善时交付缺口与候选，不伪造通过，也不重问已经授权的返工。检查器不能判断事实真假或模型是否真的在网页运行。
4. **冻结交接**：审核通过且当前授权允许继续时，用 `editorial.py freeze` 生成独立 `script.txt` 和 `handoff.json`。已有定稿选择直接沿用。没有选定稿或缺证据时交付完整候选和缺口，不调用 TTS。进入制片前再次 `verify`，防止源稿或审核后正文被改动。
5. **土豆泥制片**：读取实际安装的 `tudouni-ai-video/SKILL.md`，传入冻结正文和当前范围。沿用全文一次豆包配音、中文真实对齐、语义分镜、既有 FUGui 和当前画面规范；显式整理分镜生图包，场景/人物/道具按需分层，先审代表画面、再看动效样片、最后扩全片；文案变化必须重配音，不能沿用旧毫秒。工程放 iCloud 外，新版本单独交付。完整音频、编码、画面和听验分别记录。
6. **交付与反馈**：报告实际模型、正文版本、视频位置、实测时长与验证边界。要求同步内容时完成四平台适配和统一确认；只做私有样片时不扩成发布任务。新工作流的抖音/小红书上传使用 `tudouni-maitian-publisher`，在 ego 内操作麦田插件，保存并核验草稿；正式发布另需明确指令。同一作品不再同时触发 Qoder 上传，旧项目的既有 Qoder 记录保留。实际发布后才按 48 小时/7 日数据回到选题；没有数据不伪造运营闭环已完成。

## 本机入口

```bash
SKILL_DIR="${CODEX_HOME:-$HOME/.codex}/skills/tudouni-content-loop"
python3 "$SKILL_DIR/scripts/editorial.py" export --packet /项目/packet-v01.json --out /项目/prompt-v01.txt
python3 "$SKILL_DIR/scripts/editorial.py" accept --packet /项目/packet-v01.json --response /项目/response-v01.txt --receipt /项目/receipt-v01.json --out-dir /项目/accepted-v01
python3 "$SKILL_DIR/scripts/editorial.py" freeze --accepted /项目/accepted-v01 --review /项目/review-v01.json --out-dir /项目/frozen-v01
python3 "$SKILL_DIR/scripts/editorial.py" verify --handoff /项目/frozen-v01/handoff.json
```

当前模型本地写作可省略 receipt，但 packet 的 writer.provider 必须明确为 `local`。工具不调用浏览器、不调用 TTS、不执行发布，也不把审核状态自行设为通过。

## 恢复与记录

- 提交状态不明先回读原会话；不能重发整包。普通写作无正文增长 5 分钟才尝试原会话一次恢复，再无进展则保留现场；等待以不超过 60 秒的小段进行。已明确运行的研究任务不套普通写作恢复。
- WAV 成功、对齐失败只恢复对齐；纯画面修改复用核验过的音频。合成、发布失败不自动重复调用。
- 源事实变化使编辑审核失效；正文变化使音频与时间轴失效；封面变化只更新相关平台资产。保留旧版本，不删除用户素材。
- 原始回答、操作 receipt 和审核是不同证据。网页选中模型不代表文风更好，技术验收不代表逐字听验。
